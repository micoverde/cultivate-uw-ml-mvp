# Real feature extraction flow from src/ml/training/enhanced_feature_extractor.py
def extract_features(question_text, metadata):
    # 1. Linguistic features (40D) - TF-IDF, keywords, complexity
    linguistic = extract_linguistic_features(question_text)   # 40 dimensions

    # 2. Temporal features (15D) - Pauses, timing, flow
    temporal = extract_temporal_features(metadata)            # 15 dimensions

    # 3. Contextual features (24D) - Age, setting, complexity
    contextual = extract_contextual_features(metadata)        # 24 dimensions

    return np.concatenate([linguistic, temporal, contextual])  # 79D total

2 Feature Category Breakdown

The 79-dimensional feature vector is composed of three distinct categories, each capturing different aspects of educational questioning behavior.

Linguistic Features

40D
  • Tf
    TF-IDF Vectorization
    20 dimensions, n-grams (1,2), educational vocabulary
  • ?
    Open-Ended Keywords
    what, how, why, explain, describe, tell me about
  • Y
    Closed-Ended Keywords
    yes/no, is/are, can/do, will/would, how many
  • #
    Question Length Statistics
    Character count, word count, sentence length
  • Lx
    Lexical Diversity Metrics
    Type-token ratio, vocabulary richness score

Temporal Features

15D
  • ||
    Pause Duration & Frequency
    Mean pause length, pause count, total pause time
  • QR
    Question-Response Timing
    Pre-question wait, post-question wait time
  • ~
    Conversation Flow Metrics
    Speaker transitions, turn-taking frequency
  • %
    Educator vs Child Talk Ratio
    Speaking percentage distribution analysis

Contextual Features

24D
  • A
    Age Group Encoding
    Toddler, PreK, Kindergarten, Mixed (one-hot)
  • V
    Video Context
    Activity type, scenario, educational setting
  • Bm
    Bloom's Taxonomy Level
    6-level cognitive complexity (Remember to Create)
  • D
    Developmental Appropriateness
    Age-appropriate indicators, CLASS alignment
