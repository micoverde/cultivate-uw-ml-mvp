**Subject:** Request for Curriculum Evaluation - ML Learning Platform Based on Creative Computing Framework

Dear Dr. Brennan and Professor Resnick,

I am writing to request your evaluation of a machine learning curriculum we have developed for adult learners, which is explicitly grounded in your Creative Computing framework and computational thinking research.

## Project Overview

**Cultivate Learning** is a partnership between Bona Opera Ventures and the University of Washington, developing AI-powered tools to help early childhood educators improve their questioning techniques. We have created an accompanying learning curriculum to teach the underlying ML concepts to educators, researchers, and technical staff.

**Live Curriculum**: https://lively-water-04219020f.4.azurestaticapps.net/pages/learning.html

## Framework Application

We have adapted your Creative Learning Spiral for adult ML education:

| Phase | Original Intent | Our Application |
|-------|-----------------|-----------------|
| **Imagine** | Explore possibilities | Form hypotheses about ML system behavior |
| **Create** | Build with code | Implement real pipeline components |
| **Play** | Test and iterate | Experiment with parameters and data |
| **Share** | Connect to community | Apply learning to real classroom analysis |
| **Reflect** | Assess understanding | Interactive assessments with feedback |

## Curriculum Structure

**Two Learning Tracks (16 Modules, ~8.5 hours total)**:

### Track 1: Processing Pipeline
1. Video Input & Storage (Azure Blob)
2. Audio Extraction (FFmpeg)
3. Speech Recognition (OpenAI Whisper)
4. Speaker Diarization (pyannote)
5. Question Detection
6. Feature Extraction (19 linguistic features)
7. 3-Model Ensemble Classification
8. API & Real-time Feedback

### Track 2: Ensemble Training
1. Data Collection (26 videos, 119 annotations)
2. Expert Annotation (CLASS Framework)
3. Train/Test Split Strategy
4. Feature Engineering Design
5. Model Architecture Selection
6. Hyperparameter Optimization
7. Ensemble Weight Optimization
8. Final Evaluation (89% accuracy)

## Evaluation Request

We respectfully request your feedback on the following dimensions:

### 1. Learning Design
- Does our adaptation of the Creative Learning Spiral maintain fidelity to the original framework's principles?
- Are the "Explore → Create → Reflect" phases within each module appropriately structured?
- How well does the curriculum support constructionist learning for adult technical learners?

### 2. Learning Outcomes
- Are the stated learning objectives measurable and achievable?
- Do the assessments (interactive quizzes) adequately measure computational thinking development?
- What additional outcome measures would you recommend?

### 3. Learning Goals
- Is the progression from concrete (video processing) to abstract (ensemble methods) pedagogically sound?
- Does the curriculum appropriately balance procedural knowledge with conceptual understanding?
- Are there gaps in the learning trajectory we should address?

### 4. Pedagogy
- Does our approach honor the "low floor, wide walls, high ceiling" design principle?
- How might we better support learners with different entry points and goals?
- What scaffolding strategies would strengthen the learning experience?

### 5. Computational Thinking Integration
- How well do we address CT concepts (sequences, conditionals, data, abstraction)?
- Are CT practices (experimenting, testing, abstracting) sufficiently embedded?
- Do we adequately develop CT perspectives (expressing, connecting, questioning)?

## Context: Why This Matters

Early childhood educators significantly impact child development through their questioning techniques. Research shows open-ended questions promote deeper thinking and language development, yet many educators default to closed-ended questions.

Our ML system classifies educator questions in real-time, providing actionable feedback. The curriculum helps stakeholders understand *how* the system works, building trust and enabling informed use of AI tools in educational settings.
