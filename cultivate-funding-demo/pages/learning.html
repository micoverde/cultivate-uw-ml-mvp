Audio Extraction with FFmpeg
30 min

Extract and normalize audio streams from video files, preparing them for speech recognition.

FFmpeg commands Sample rate conversion Audio normalization
Explore: Why 16kHz Mono? 10 min

Whisper and most speech recognition models expect specific audio characteristics:

1

16kHz Sample Rate

Human speech frequencies (85Hz-255Hz fundamentals, up to 8kHz harmonics) are fully captured at 16kHz. Higher rates waste compute without improving accuracy.

2

Mono Channel

Speech recognition processes single-channel audio. Stereo adds complexity without benefit for transcription.

3

PCM 16-bit

Uncompressed PCM preserves audio fidelity. 16-bit depth provides 96dB dynamic range - more than sufficient for speech.

Create: FFmpeg Pipeline 15 min
# FFmpeg command for Whisper-compatible audio extraction ffmpeg -i classroom_video.mp4 \ -vn \ # Strip video stream (audio only) -acodec pcm_s16le \ # 16-bit PCM encoding -ar 16000 \ # 16kHz sample rate -ac 1 \ # Mono channel -af "highpass=f=80,lowpass=f=8000" \ # Speech frequency filter output_audio.wav # Python wrapper for programmatic use import subprocess def extract_audio(video_path: str, output_path: str) -> bool: cmd = [ "ffmpeg", "-i", video_path, "-vn", "-acodec", "pcm_s16le", "-ar", "16000", "-ac", "1", output_path ] result = subprocess.run(cmd, capture_output=True) return result.returncode == 0

Speech Recognition with Whisper
35 min

Explore: Whisper Model Architecture 15 min

OpenAI Whisper is a transformer-based encoder-decoder model trained on 680,000 hours of multilingual audio:

1

Model Sizes

tiny (39M params) | base (74M) | small (244M) | medium (769M) | large (1.5B)

2

Accuracy vs Speed Trade-off

We use base model (~140MB) for optimal balance - 5x faster than large with comparable accuracy for English speech.

Create: Transcription Pipeline 15 min
# From src/ml/audio/whisper_processor.py import whisper # OpenAI Whisper (PyTorch-based) class WhisperAudioProcessor: def __init__(self, model_size: str = "base"): # Load pre-trained model (downloads ~140MB on first run) self.model = whisper.load_model(model_size) def transcribe(self, audio_path: str) -> dict: """Transcribe audio with word-level timestamps.""" result = self.model.transcribe( audio_path, word_timestamps=True, # Enable precise timing language="en", # Force English task="transcribe" # (vs "translate") ) # Extract segments with timing info segments = [] for seg in result["segments"]: segments.append({ "text": seg["text"].strip(), "start": seg["start"], "end": seg["end"] }) return {"segments": segments, "full_text": result["text"]}
