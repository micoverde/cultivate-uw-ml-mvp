Explore: Understanding the Challenge 8 min

Think about what happens when you record a video on your phone. Where does it go? How do you share it? Classroom videos have similar challenges, but bigger:

1

Video Files Are Large

A single classroom video might be several gigabytes - like hundreds of photos combined. We need powerful computers to store and process them.

2

Privacy Is Essential

Videos contain children and teachers. Just like medical records, they must be stored securely with strict access controls.

3

Multiple People Need Access

Researchers, coaches, and teachers may all need to view the same video. Cloud storage lets authorized people access files from anywhere.

Create: See the Code 7 min

Here's the actual computer code that uploads a video to secure cloud storage. Don't worry about understanding every line - just notice the structure:

# This code uploads a classroom video to secure cloud storage # Think of it like a very smart filing system def upload_classroom_video(video_file, video_name): """ Upload a video to secure cloud storage. video_file: The video from the camera video_name: What we want to call it """ # Connect to our secure storage (like logging into iCloud) storage = connect_to_secure_storage() # Create a folder for classroom videos folder = storage.get_folder("classroom-videos") # Upload the video with a label saying it's from a classroom folder.upload( file=video_file, name=video_name, labels={"type": "classroom", "status": "new"} ) return "Video uploaded successfully!"

Key insight: The code follows the same logic you would use - connect to storage, find the right folder, put the file there with a label.

Explore: Why Separate Audio? 8 min

Think of a video file like a book with pictures - it contains both visual information and sound. To analyze what people are saying, we need to extract just the audio part:

1

Speech Recognition Needs Audio Only

The computer that converts speech to text works only with sound. Including video would confuse it and slow things down.

2

Specific Format Required

Speech recognition works best with audio at 16,000 samples per second (16kHz) in a single channel (mono). This captures all human speech sounds without extra data.

3

Smaller Files, Faster Processing

Audio-only files are much smaller than video files, so the computer can work with them faster.

Create: The FFmpeg Command 7 min

FFmpeg is a free tool that can manipulate audio and video. Here's the command we use:

# FFmpeg command to extract audio for speech recognition # Think of it as instructions for a very capable assistant ffmpeg -i classroom_video.mp4 \ # "Take this video file..." -vn \ # "...remove the video part..." -ar 16000 \ # "...sample audio 16,000 times per second..." -ac 1 \ # "...use one audio channel..." output_audio.wav # "...and save it as this audio file" # The result: A clear audio file ready for speech recognition!

Analogy: It's like photocopying just the text from a picture book - you get exactly what you need in a simpler format.

Explore: How Whisper Learns 10 min

Whisper is an AI model created by OpenAI that learned to transcribe speech by listening to 680,000 hours of audio from the internet. That's equivalent to listening non-stop for 77 years!

1

Learning from Examples

Whisper learned by seeing millions of examples of audio paired with written transcripts, like a child learning language by hearing words and seeing them written.

2

Different Sizes for Different Needs

Whisper comes in sizes: tiny (fast, less accurate), base (balanced), medium (more accurate), large (most accurate but slow). We use "base" for good accuracy with reasonable speed.

3

Timestamps Are Key

Whisper can tell us exactly when each word was spoken, down to fractions of a second. This lets us match words to specific moments in the classroom interaction.
